# 프리티걸 옷입히기 🎀

브라우저에서 바로 즐기는 여자아이 옷입히기(dress-up) 게임입니다.
빌드 도구 없이 순수 HTML/CSS/JS로 만들어졌으며, 캐릭터는 전부 SVG로 그려집니다.

## 실행 방법

정적 파일이므로 아무 웹 서버로 열면 됩니다.

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

또는 `index.html`을 브라우저에서 바로 열어도 동작합니다.

## 기능

- **배경**: 6가지 색상 테마
- **피부톤**: 6가지 톤 선택
- **헤어스타일 & 컬러**: 5가지 스타일 × 11가지 컬러
- **표정**: 4가지 표정
- **의상 & 컬러**: 6가지 스타일(미니원피스, 롱드레스, 셔츠+팬츠 등) × 12가지 컬러
- **신발 & 컬러**: 5가지 스타일 × 12가지 컬러
- **액세서리**: 안경/모자/목걸이/리본/귀걸이 (다중 선택)
- **🎲 랜덤**: 전체 코디를 무작위로 조합
- **↺ 초기화**: 기본 코디로 복원
- **💾 이미지로 저장**: 완성한 캐릭터를 PNG로 다운로드

## 파일 구조

- `index.html` — 페이지 구조
- `style.css` — 레이아웃/디자인
- `script.js` — 캐릭터 SVG 생성 및 UI 로직
